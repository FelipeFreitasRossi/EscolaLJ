# Imagens do site

- `demo/` — imagens ilustrativas geradas por código, só para demonstração.
  Não mostram as instalações nem os alunos da LJ. O site exibe o selo
  "Imagem ilustrativa" sobre elas.
- `oficiais/` — coloque aqui as fotos oficiais da LJ.

Para trocar uma imagem: edite `frontend/src/data/images.ts`, aponte o `src`
para `/images/oficiais/nome-da-foto.webp`, ajuste `width`/`height` e mude
`demo` para `false`.

Dicas: use .webp ou .jpg com até ~1920 px de largura e menos de 300 KB.
Fotos de menores de idade só com autorização dos responsáveis.
